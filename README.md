# 📊 Exploratory Data Analysis (EDA) for Regression Dataset

This project demonstrates a complete **Exploratory Data Analysis (EDA)** workflow on a numerical regression dataset using Python.

The notebook focuses on:
- Understanding dataset structure
- Visualizing feature distributions
- Detecting outliers
- Exploring correlations
- Preparing data for machine learning models
